# Фрактальная мастерская

Программа на Python (библиотека `turtle`): пользователь выбирает фрактал в меню,
вводит параметры, программа рисует его рекурсивными функциями.

## Запуск
```
python main.py
```
Ну[THEORY.md](THEORY.md)жен Python 3.8+ (turtle входит в стандартную библиотеку; на Linux может
понадобиться `sudo apt install python3-tk`).

## Как пользоваться
1. Запустите программу - появится меню из 10 пунктов.
2. Введите номер фрактала.
3. Введите глубину, размер и т.д. (Enter = значение по умолчанию).
   Если ввести ерунду или число вне диапазона - программа переспросит.
4. Рисунок появится в окне. После этого снова меню - можно рисовать другой фрактал.
5. Пункт 10 - выход.

## Структура
```
fractal_workshop/
├── main.py              Роль 4: меню, ввод, главный цикл
├── fractals/
│   ├── __init__.py
│   ├── utils.py         общие функции (перенос черепашки, цвета)
│   ├── basic.py         Роль 1: двоичное дерево, "Ветка"
│   ├── koch.py          Роль 2: Кох, снежинка Коха, Минковский
│   └── complex.py       Роль 3: ледяные 1 и 2, Леви, дракон
├── README.md
└── THEORY.md            теория по ролям + шпаргалка для защиты
```

## Рекомендуемая глубина
| Фрактал | Можно | По умолчанию |
|---|---|---|
| Двоичное дерево | 0-12 | 6 |
| Ветка | 0-8 | 5 |
| Кох / снежинка | 0-6 | 4 |
| Минковский | 0-5 | 3 |
| Ледяной №1 | 0-5 | 3 |
| Ледяной №2 | 0-6 | 4 |
| Леви / дракон | 0-14 | 10 |

Чем больше глубина, тем дольше рисуется (количество отрезков растёт в разы с каждым шагом).
